# 📧 AI Email Generator (Streamlit)

An AI-powered email generation web application built using **Streamlit** and **Google Gemini API**.  
This app allows users to generate professional emails using predefined templates or fully custom AI-generated content.

---

## 🚀 Features

- Multiple email templates (Request, Apology, Follow-up, Invitation, etc.)
- AI-powered email improvement and generation
- Editable email preview
- Secure API key handling using Streamlit secrets
- Clean and interactive UI
- Ready for deployment on Streamlit Cloud

---

## 🛠️ Tech Stack

- Python 3.10+
- Streamlit
- Google Generative AI (Gemini)
- TOML (for secrets management)
